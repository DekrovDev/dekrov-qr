# Dekrov-qr — QR Code Generator

A lightweight, privacy-friendly QR code generator that runs entirely in your browser.

Create customizable QR codes for links, text, Wi-Fi networks, phone numbers, emails, and contacts. Download the result as PNG or SVG.

## Live Demo

[Open Dekrov-qp](https://DekrovDev.github.io/YOUR_REPOSITORY/)

## Features

- Link QR codes
- Plain text QR codes
- Wi-Fi connection codes
- Phone number codes
- Email codes with optional subject
- Contact cards in vCard format
- Custom QR and background colors
- Transparent background
- Adjustable export resolution
- PNG and SVG downloads
- Input validation and contrast checking
- Responsive design for desktop and mobile
- No registration or backend required
- QR generation happens locally in the browser

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- [QR Code Generator](https://github.com/kazuhikoarase/qrcode-generator)

## Run Locally

Clone or download the repository, then open `index.html` in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.

## Deploy with GitHub Pages

1. Open the repository settings.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Save the settings.

GitHub will publish the website automatically.

## Privacy

QRly does not send entered content to a server. QR codes are generated locally inside the browser.
